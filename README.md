# rock-paper-scissors-game
A simple and interactive Stone Paper Scissors (Rock Paper Scissors) game built using HTML, CSS, and JavaScript. Play against the computer and see who wins the best of three rounds!

🎮 Features
Clean and responsive UI

Real-time score updates

Randomized computer choice

Win/Lose/Draw message for each round

Reset button to play again

🛠️ Technologies Used
HTML5 – Markup for the game structure

CSS3 – Styling and layout

JavaScript – Game logic and interactivity

File Structure
stone-paper-scissors/
│
├── index.html      # Main HTML file
├── style.css       # CSS styling
└── app.js       # JavaScript logic

🎯 How to Play
Click on Stone, Paper, or Scissors.

The computer will randomly select its move.

The winner of the round will be displayed.

Continue playing and check your score!
